Star Strider | New Stock-alike Crew Spacecraft | v0.9.0

This mod adds multiple parts for you to make the Star Strider spacecraft, with many part switches to allow for kitbashing too. This mod is heavily inspired by this concept by Maciej Rebisz (https://www.artstation.com/artwork/8emN3n)

FEATURES
- 4 crew capacity Star Strider pressure vessel with 2 window-size configurations
- 2.5m Star Strider capsule control module
- 2.75m Heat shield with low orbit and lunar return configurations.
- Jettisonable parachute bay cover, with and without a built-in deployable nose cone.
- 2.75 to 2.25m Service Module adapter with integrated RCS thrusters
- 2.25m/1.875m configurable cryogenic Service Module
- Deployable tracking 3-segment solar panels
- 1.875m spacecraft truss decoupler
- 1.875m to 2.75m spacecraft adapter with a 2.75m aerodynamic fairing
- Generic small multi adapter that adapts the 2.75m service module to 1.875m, 2.5m, 3.125m, 3.375m, 3.5m and 3.75m.
- Paint variants for the capsule, parachute bay cover and docking port cover (Panels and Blankets)
- Mod bundles the BDB RL-10, used with permission.
- Custom IVA with RPM and FreeIVA support that adapts to selected window size
- Waterfall plumes for RCS and engines. (RCS plumes originally by yobeefjerky, Abort motor plume by Rodg88, modified by me)
- Smokescreen configs for Abort motors. (Configs based on Avalanche by Kochi and effects by MP_Nazari)
- Support for Shaddy
